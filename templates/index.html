MUSIC BOT - VERCEL VERSION

⚠️ Lưu ý quan trọng khi up lên Vercel:

Vercel chỉ host được GIAO DIỆN WEB này thôi. Bot nhạc Discord cần chạy liên tục (pip + ffmpeg + kết nối voice) nên Vercel sẽ tự tắt sau 10 giây và không phát được nhạc.

Để bot chạy 24/7 bạn phải host file bot.py trên Render.com hoặc Railway.app (free) - Mình đã để sẵn file bot.py và hướng dẫn trong README.md

🔑 Token Bot (Demo giao diện)

Sau khi deploy lên Vercel, trang này sẽ hiện online nhưng bot.py sẽ không chạy được trên Vercel.

🚀 Cách up lên Vercel đúng

  1. Vào vercel.com -> Add New Project -> Import Git Repository (up code này lên GitHub trước)
  2. Framework Preset: Other
  3. Build Command: để trống
  4. Deploy -> xong, bạn sẽ có link https://ten-project.vercel.app
  5. Nhưng đây chỉ là web. Để chạy bot thật, đọc phần dưới

✅ HOST BOT THẬT 24/7 (KHUYÊN DÙNG):

1. Giữ lại file bot.py trong zip này

2. Vào render.com -> New -> Background Worker -> chọn repo này

3. Start Command: python bot.py

4. Add Env: DISCORD_TOKEN=token của bạn

5. Deploy -> bot sẽ online 24/7
